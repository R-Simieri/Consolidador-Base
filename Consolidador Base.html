Como Usar os Filtros

Filtro por Nº de Negociação:

  • Digite os números separados por vírgula: 100800, 100804, 100805
  • Para um intervalo, use hífen: 100800-100805
  • Deixe em branco para mostrar todos os negócios

Filtro por NFSe:

  • Digite os números separados por vírgula: 18464, 18447, 18443
  • Para um intervalo, use hífen: 18464-18447
  • Deixe em branco para mostrar todas as NFSe

Filtros de Data:

  • Selecione o tipo de data para filtrar
  • Defina uma data inicial e/ou final
  • Deixe em branco para não filtrar por data
